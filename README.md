## Нені жасадым
- HTML5 семантикалық тегтер: `header`, `nav`, `main`, `section`, `article`, `footer`
- Блоктар: мәзірі бар header, "Біз туралы", "Қызметтер", "Байланыс"
- Байланыс формасы: `name`, `email`, `message` өрістері, әрқайсысында `label` және `required`
- Суретте `alt` бар, тақырыптар h1 → h2 → h3 ретімен
- `head` ішінде: `title`, `meta description`, `meta viewport`, favicon
- Адаптивті CSS: 375 px және 1280 px енінде дұрыс көрінеді
- GitHub Pages арқылы жарияланды (main бұтағы)
